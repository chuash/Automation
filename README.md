> **Note:** The `requirements.txt` file in this repository was generated for a Python 3.13 environment.

This project is a proof of concept (POC) that aims to:

1. Automate the process of:
   - opening URLs in a browser tab,
   - scrolling through web pages, and
   - capturing screenshots of the displayed content.

2. Extract relevant information from the captured screenshots by processing the images with a suitable Vision Language Model (VLM).
